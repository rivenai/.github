# Riven AI

**One API. 75+ models. One bill.**

Riven is a transparent multi-model AI platform that unifies frontier, open-weight, and custom-tuned LLMs behind a single OpenAI-compatible endpoint. No token markup, no credit fees — vendor list pricing with full governance.

## What we build

| Project | Description |
|---|---|
| [riven-sdk](https://github.com/rivenai/riven-sdk) | Official Python and JavaScript SDKs |
| [riven-cookbook](https://github.com/rivenai/riven-cookbook) | Examples, guides, and recipes for building with Riven |
| [riven-mcp](https://github.com/rivenai/riven-mcp) | Official MCP server — bring Riven into any MCP client |

## Key features

- **75+ models** from OpenAI, Anthropic, Google, Mistral, Moonshot, DeepSeek, and more
- **OpenAI-compatible** — drop-in `/v1/chat/completions` endpoint
- **Multi-model routing** — automatically pick the best model per request
- **Transparent pricing** — vendor list pricing, no markup, no credit fees
- **Self-hosted deployment** — single-tenant, dedicated infrastructure
- **Riven Control** — governance: budgets, rate limits, audit logs, per-key controls
- **MCP support** — connect Riven to Claude Desktop, Cursor, or any MCP client
