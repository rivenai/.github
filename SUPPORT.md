# Getting Support

This document covers how to get help with Riven AI products. For development contributions, see [CONTRIBUTING.md](./CONTRIBUTING.md). For security issues, see [SECURITY.md](./SECURITY.md).

## I'm a Riven AI customer or partner

Use your dedicated support channel established at onboarding. If you have lost access, email **hello@riven.ai** and we will route you.

## I'm using a public Riven AI repository

Most rivenai/* repositories are private. For the small set of public repos:

- **Bug reports** — open a GitHub issue using the [bug report template](https://github.com/rivenai/.github/blob/main/.github/ISSUE_TEMPLATE/bug_report.yml). Include a minimal reproduction.
- **Feature requests** — open a GitHub discussion before opening an issue. Explain the use case.
- **Usage questions** — open a GitHub discussion under the `Q&A` category.
- **Documentation gaps** — open an issue with the `docs` label.

## What we do NOT support here

- Sensitive customer data, account access, or billing inquiries (use your support contract).
- Third-party software that integrates with Riven AI but is not built by us.
- Off-topic AI/ML questions.

## Response Times

For public-repo issues and discussions, response times are best-effort. We triage weekly. For paid customers, refer to your contract SLA.

## Stay Informed

- **Releases** — watch the relevant repository on GitHub.
- **Security advisories** — watch the rivenai/ organization for security advisories.
- **General announcements** — follow updates at https://riven.ai (when public).
